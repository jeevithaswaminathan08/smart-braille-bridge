# Smart Braille Bridge

## Project Overview
Smart Braille Bridge is a wearable communication glove designed to convert six-dot Braille input into readable text and speech.

## Hardware
- ESP32 microcontroller
- Six TTP223 touch sensors
- Wearable glove
- Rechargeable power supply

## Working Principle
1. Touch sensors capture the six-dot Braille pattern.
2. The microcontroller decodes the pattern into a character.
3. Bluetooth sends the decoded text to a mobile application.
4. The application displays the text and reads it aloud using text-to-speech.

## Planned Features
- Six-dot Braille input
- Braille-to-text conversion
- Bluetooth connectivity
- Mobile text display
- Speech output
